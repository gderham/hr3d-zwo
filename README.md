This repository contains Zwift custom workout files based on the [Haute Route 3 Day Event training plan](https://cdn.shopify.com/s/files/1/0507/5078/3660/files/WB17_0198_Training_Plan_Haute_Route_3_Day_v2.pdf?v=1610459048) which is a very effective twelve week training plan for endurance cycling. I have used it multiple times to get fit for cycling trips, Fred Whitton, Marmotte etc.

To load the workouts into Zwift, follow these [instructions](https://support.zwift.com/en_us/custom-workouts-ryGOTVEPs#Importing_Custom_Workouts_Today's_Plan_or_TrainingPeaks) to import the files in the Workouts directory.

The workouts are named like "HR3D w1 Mon" meaning the Monday workout for week 1.
